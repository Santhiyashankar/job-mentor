# JobMentor – AI-Powered Job Application Tracker 🚀

JobMentor is a full-stack web application that helps job seekers track applications and receive **AI-powered rejection insights** to improve future job success.

## ✨ Features
**🔐 Authentication

Secure user authentication

Protected routes and session handling

**📋 Job Application Management

Add, edit, delete job applications

Track application status:

Applied

Interview

Rejected

Offer

**🤖 AI Rejection Insights

AI analyzes rejected applications

Provides:

Possible rejection reasons

Resume improvement tips

Interview improvement suggestions

Actionable next steps

**📊 Dashboard & Analytics

Clean dashboard UI

View rejected applications separately

Search and filter applications by company or role

**⚙️ Settings & UX

Professional sidebar navigation

Responsive layout

Clean, modern UI using Tailwind CSS

## 🛠 Tech Stack
**Frontend

**Backend
