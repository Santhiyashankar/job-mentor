# JobMentor – AI-Powered Job Application Tracker 🚀

JobMentor is a full-stack web application that helps job seekers track applications and receive **AI-powered rejection insights** to improve future job success.

## ✨ Features
- User authentication (Login / Signup)
- Track job applications (Applied, Interview, Rejected, Offer)
- AI-powered rejection analysis & improvement tips
- Analytics dashboard
- Clean, professional UI
- Secure backend API

## 🛠 Tech Stack
**Frontend**
- React
- TypeScript
- Tailwind CSS
- Vite

**Backend**
- Node.js
- Express.js
- OpenAI API (AI Insights)
