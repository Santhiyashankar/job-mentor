# JobMentor 🚀  
### AI-Powered Job Application Tracker with Rejection Intelligence

---

## 📌 Overview

**JobMentor** is a full-stack web application that helps job seekers track their job applications and gain **AI-powered insights from rejections** to improve future interview success.

Unlike traditional job trackers, JobMentor analyzes rejected applications and provides **actionable suggestions** such as resume improvements, interview tips, and skill-gap analysis.

---

## ✨ Features

### 🔐 Authentication
- Secure login & signup
- Protected dashboard routes

### 📋 Job Application Management
- Add, edit, delete applications
- Track application status:
  - Applied
  - Interview
  - Rejected
  - Offer

### 🤖 AI Rejection Insights
- AI-generated feedback for rejected applications
- Includes:
  - Possible rejection reasons
  - Resume improvement tips
  - Interview improvement guidance
  - Actionable next steps

### 📊 Dashboard & Analytics
- Clean dashboard UI
- Filter & search applications
- Separate AI Insights page for rejected jobs

### 🎨 UI & UX
- Modern, responsive design
- Built with Tailwind CSS
- Sidebar navigation & professional layout

---

## 🛠 Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- React Router
- React Hook Form

### Backend
- Node.js
- Express.js
- REST APIs

### Database & Auth
- Supabase (PostgreSQL + Authentication)

### AI Integration
- OpenAI API for rejection insights
